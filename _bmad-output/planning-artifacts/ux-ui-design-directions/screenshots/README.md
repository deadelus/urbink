# Captures Urbink

Captures des 5 onglets principaux du prototype `Urbink App.html`. Mode clair par défaut.

| # | Fichier | Onglet | Contenu |
|---|---|---|---|
| 01 | `01-carte.png` | Carte | Vue carte principale Paris — pierres déverrouillées sur monuments, FAB création parcours, recherche en haut |
| 02 | `02-parcours.png` | Parcours | Liste des parcours (À découvrir / Mes itinéraires) avec progression et titres « Légende de Paris » |
| 03 | `03-social.png` | Social | Feed social — runs récents d'amis avec sceaux/pierres collectés |
| 04 | `04-badges.png` | Badges | Grille de badges (déverrouillés + verrouillés) avec progression |
| 05 | `05-profil.png` | Profil | Profil enrichi — carte de rang Topaze + barre XP vers Jade, stats, dernières villes (Paris/Lisbonne/Londres) |

## Écrans overlay (non capturés en PNG mais vérifiés en live)

- **Mes villes** (depuis Profil → carte ville) : tri par maîtrise, titres distincts par ville (« Légende de Paris », « Mémoire de Lisbonne », « Visiteur de Londres »), progression vers titre suivant
- **Détail ville** : mosaïque de monuments, sceaux collectés, parcours suggérés
- **Création de parcours** : sélection de monuments + thème, prévisualisation distance
- **Filtres carte** : époques, types de monuments, difficulté
- **Réglages** : langue (FR/EN), thème (clair/sombre), notifications

## Re-générer les captures

Ouvrir `Urbink App.html` dans le preview et utiliser le toggle d'onglet du bas pour naviguer. Mode clair recommandé pour la doc, sombre activable via Tweaks.
