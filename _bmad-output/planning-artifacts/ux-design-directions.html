Direction 03 — v4
Carte — Session active (Circuit libre & Itinéraire)
⚠️ v4 : Circuit libre = mode par défaut, enregistre les stats (rues, distance, durée). Itinéraire = mode GPS uniquement (comme un GPS classique) — pas d'enregistrement ; les check-points sont mémorisés pour les itérations, la progression est réinitialisable. Les zones explorées (rues colorées) ne sont jamais reset. Transport auto-détecté (vitesse GPS). SessionStatusBar Terra Cotta (circuit libre) ou Ocre (itinéraire). Bouton Arrêter 52px bas-droite. Sélecteur de navigation uniquement en mode itinéraire — GPS intégré ou app externe (Waze voiture uniquement · Plans · Google Maps) ; circuit libre n'a pas de navigation externe.

Filtres POI — Affichage rapide & Écran complet
Deux niveaux de filtres. Niveau 1 (inline) : chips scroll horizontal sous la searchbar — 4–5 types courants visibles + bouton "Voir plus →". Niveau 2 (écran) : modal/push navigation avec tous les filtres organisés en catégories, multi-sélection, chips de réinitialisation. Tap "Voir plus →" ou swipe depuis les chips ouvre l'écran complet.
