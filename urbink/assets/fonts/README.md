# Polices custom Urbink

Ce répertoire contient les fichiers de polices TTF utilisés par l'app.

## Polices requises

### Crimson Pro (display / heading)
Télécharger depuis : https://fonts.google.com/specimen/Crimson+Pro

Fichiers attendus :
- `CrimsonPro-Regular.ttf`
- `CrimsonPro-SemiBold.ttf`
- `CrimsonPro-Italic.ttf`

### Inter (body)
Télécharger depuis : https://fonts.google.com/specimen/Inter

Fichiers attendus :
- `Inter-Regular.ttf`
- `Inter-Medium.ttf`
- `Inter-SemiBold.ttf`

## Installation

1. Télécharger les polices depuis Google Fonts
2. Extraire les fichiers TTF dans ce répertoire
3. Lancer `flutter pub get` pour recharger les assets
4. Relancer l'app

> Les fichiers TTF ne sont pas commités dans le repo (gitignored) car ils sont redistribuables sous licence OFL-1.1.
> Chaque développeur doit les télécharger localement.
